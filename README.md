# Music Archive

개인 음악 취향 아카이브 웹사이트입니다. 3개의 화면으로 구성됩니다.

- 앨범 보관함: 앨범명, 아티스트 이름, 장르, 평점, 리뷰
- 라이브 보관함: YouTube 영상 ID, 아티스트 이름, 평점, 리뷰
- LP 소장 목록: LP 소장 내역, 아티스트, 발매 년도/앨범 제작 년도

## Google Sheets 입력 형식

### 앨범 시트

| 컬럼 | 예시 |
|---|---|
| album_name | OK Computer |
| artist_name | Radiohead |
| genre | Alternative Rock |
| rating | 9.5 |
| review | 혼란과 사랑이 동시에 흐르는 앨범 |
| best track | Paranoid Android |

### 라이브 시트

| 컬럼 | 예시 |
|---|---|
| youtube_video_id | dQw4w9WgXcQ |
| artist_name | Khruangbin |
| rating | 9.0 |
| review | 무대 위 여유가 정말 좋았다 |
